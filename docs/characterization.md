# Macro characterization (post-PnR)

Generated by `tools/characterize.py` from the LibreLane run results. `f_max = 1 / (T_clk - worst_setup_slack)`, worst slack taken over all PVT corners. `PEX` = SPEF from `OpenROAD.RCX` was available to the post-PnR STA. `status` refers to setup; `hold WS` is reported separately.

Caveats: OR1 has a single `TT_5P0` corner only (no slow/fast corner; its liberty header states the DFF setup/hold tables are not characterised yet), so its f_max is an optimistic TT estimate, not signoff grade. OR1's worst path is also I/O-dominated (10 ns of external input delay in the audiodac path), so it is not a pure gate-speed measurement; see docs/or1_characterization.md for the I/O vs register-to-register split. `util %` and `cells` are LibreLane's stdcell metrics; on ics55 the deck classifies filler cells as `other`, so both read high.
